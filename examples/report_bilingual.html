Usage / 使用说明

This is a fictional example for checking the public release’s report format. It contains no lab manuscript or private feedback and demonstrates no model review accuracy.

Revision priority: High means the author needs to resolve the stated condition before relying on the affected claim. A suggested passage changes wording only when its facts have been confirmed.

修改优先级：高表示作者需要先解决列明的条件，才能依赖相应主张。建议文本只有在事实已确认时才可采用。

Content and technical comments / 内容与技术意见

Detector input / 检测器输入

1. State the information used by the detector / 说明检测器使用的信息

Revision priority: High

Location: Fictional page 1, receiver model paragraph.

Original: The receiver observes

y=Hx+z. y=Hx+z.

The detector uses the channel response.

Comment: The equation names the channel response, but the supplied toy passage does not explain how the detector obtains it. A model variable’s appearance does not establish that it is available during execution. This remains an author-dependent information check.

Suggested revision: Confirm whether the detector receives the exact response or an estimate, identify its source and when it becomes available, and synchronize the detector’s notation and assumptions. Preserve the observation equation if it is correct; do not invent a training protocol or an accuracy guarantee.

审阅意见： 公式定义了信道响应，但所给的虚构段落没有说明检测器如何取得它。变量出现在模型中，并不代表执行时已经可用。这里需要作者确认实际的信息条件。

建议修改： 确认检测器使用真实响应还是估计值，说明来源和取得时点，并同步检测步骤的符号及假设。原观测公式若成立应予保留；不能编造训练协议或精度保证。

Local wording after factual confirmation / 事实确认后的局部建议文本

Use the following wording only if the author confirms that the channel estimate is already available before detection. It implements the information-source part of the revision; the estimation method and error assumptions still require a factual account.

只有作者确认检测前已经取得信道估计时，才可使用下文。它只落实信息来源的说明；估计方法和误差假设仍需根据实际方案补充。

Suggested wording / 建议文本:

The detector uses the channel estimate available before detection, which is distinct from the channel response appearing in the observation model.

Organization and flow comments / 篇章与行文意见

Location: Fictional page 1, immediately before the detector step.

审阅意见： 确认信息来源后，将说明放在首次使用前，可以减少读者往返查找。这是可选的组织调整；现有明确的局部回指也可以充分。

建议修改： 如果实际阅读顺序因此更清楚，可将已有且有事实支持的输入说明移至检测器首次使用处，同时更新交叉引用，并将估计细节保留在相应小节。
