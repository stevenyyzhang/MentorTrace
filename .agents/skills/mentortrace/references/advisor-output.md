# Advisor output contract v1

## Economical review

`advisor_efficiency: 1` is frozen only for new runs. Grouped non-action output is
`expression_assessment_groups:[{id:"STAGE:WG1",source_ids:[...],decision,reason,target_anchors:[]}]`.
The decoder expands the explicitly named members with transfer IDs
`group.id + "." + source_id`. No omitted source receives a decision. KEEP needs
common target evidence. Different conditions, reasons or targets require separate
groups or individual brief records. Groups cannot replace actionable evidence.
Use those expanded IDs in explicit use dispositions. Neither family membership nor
association with a Concern proves applicability. Unfinished cases stay unfinished.

The program supplies broad operation families without removing individual cases.
Inspect their operations and distinct conditions in this one call. Clear errors and
useful revisions have priority over exhaustive stylistic alternatives; do not find
one correct sentence merely to discharge a source. Concern remains independent
full-paper review; Reader/Expert planning is unchanged.

The review view omits before_account, observed_change, changed_relationship,
after_account and retrieval_terms. Full records remain local. Operations, concrete
examples, admission/source roles, feature information, scope, conditions, factual
qualifications and prohibitions remain available. These omitted narratives may
contain useful contextual nuance: this is a disclosed quality/time tradeoff, not
lossless evidence compression. Do not cite omitted narratives as supplied evidence.

Use `{"$anchor":"P2.14"}` or a contiguous passage range for extraction evidence.
For mathematical glyphs and page layout use
`{"$image_anchor":{"page":2,"description":"Equation (5), right column; describe the inspected evidence"}}`.
The decoder validates the page and copies the explicit description; it never
converts a failed quote into an image observation. Source IDs locate evidence but
do not prove correctness. Prior frozen protocols remain unchanged.

New direct public-library runs pin `advisor_output_contract: 1`. Keep historical
requests and responses unchanged. This is one full-manuscript review of every
assigned Concern, Expression and active use, with the same capacity reserves,
workload limits, original-page evidence and substantive validation.

The model decides applicability, sufficiency, uncertainty, expression contribution,
specific target comparisons, conditions, counterevidence and actions. Each source
and use has an explicit disposition. All 271 originally unlinked Expressions still
search the full manuscript. A Concern nonmatch cannot exclude an Expression.

Write a genuinely shared analysis once and reference it in the check and relevant
transfers. Keep source-specific comparisons and exceptions distinct. Every ordinary
judgment field must expand to its full actual content. A no-change decision still
needs evidence and a concrete explanation; do not replace review with a status list.
Required/optional repairs retain their actual gain, source language features,
applicable boundaries, target facts, alternatives, dependencies and output links.
Full source language remains available to the existing later drafting stage.

`scripts/advisor_output.py` defines the executable format:

- Return `advisor_output_version`, `definitions` and `response`. `$same` references
  an exact declared value; `$rows` removes repeated field names/constants only.
- `$input` copies an explicitly selected supplied string. It cannot create a target
  fact. Literal source excerpts remain supported. Do not recopy fixed library text.
- Exact extraction lines have stable passage IDs. `$anchor` binds a selected line
  or contiguous range to its actual page and text. This does not repair interleaved
  columns, certify the selected target, or establish formula glyph correctness.
  Use actual page-image evidence when extraction is inadequate; never convert an
  unverified quotation into an asserted image observation just to pass validation.
- A transfer's supplied source ID determines its unique source kind. Explicit
  no-output decisions determine empty finding/suggestion lists. The decision
  determines only unambiguous contribution roles; repair type, feature IDs and
  supporting Concern IDs still require explicit judgment.
- A one-based use ID expands the corresponding frozen source/target tuple.
  Completion status, transfer links and use-specific reasoning remain model output.
- Check-to-finding backlinks are the inverse of explicit finding-to-check links.
  No transfer-to-check relationship is inferred from historical associations.

Keep the original model envelope unchanged. Normalization/import expands it into
a separate canonical response with recorded provenance. Run the ordinary writing,
Concern, Expression contribution, source-use, anchor and finding validators before
acceptance. Dangling references, cycles, malformed tables and unknown locations
fail. Missing judgments, uses or sources are never defaulted to completed, keep,
unknown or not-applicable. Valid legacy canonical responses remain readable.

Inspect all defects in a returned packet before any corrective call. Reuse valid
unchanged material. Only a new actual inspection can supply missing judgments or
correct a substantive target error. Check completion records after interruption
before retrying; the output format does not authorize automatic network retries.
`response_preflight.json` collects missing source/use dispositions, judgment fields,
check links, contribution defects and unresolved anchors together. It is a local
deficiency inventory, never a substitute for the ordinary validator or a semantic verdict.


# Brief Expression assessment

New runs pin `advisor_expression_brief: 1`; frozen older runs do not inherit it.
This protocol uses limited-depth non-action Expression assessments; disclose that
coverage boundary. It does not imply a new user has approved any model setting.
All complete sources and active uses are still supplied. Concern checks retain
their ordinary evidence requirements. Expression review favors clear corrections
and useful improvements rather than exploring every stylistic alternative.

For non-action Expressions, return a writing transfer with `id`, `source_id`,
`assessment: "brief"`, `decision`, `reason`, and `target_anchors`. Decisions are
`keep`, `not_applicable`, `unknown`, or `unfinished`. Usually one short sentence
is enough for the operation-specific target comparison. KEEP needs a genuine
target anchor; uncertainty or incomplete inspection must remain explicit.
The native output decoder adds only empty link arrays and non-adoption metadata.
No separate formal check, source excerpt or six-field narrative is required for
these records. The brief reason can serve as a use's `reason_ref` only when it
actually addresses that use's conditions. All use dispositions remain explicit.

Repairs and optional improvements use the full existing evidence contract. A
brief record cannot claim an output, adopted feature or supporting Concern.
Discovering an error while judging an unsuitable historical edit still requires
carrying the target error into a finding; source inapplicability does not erase it.
No pre-task map or second review pass is introduced. No capacity reserve, corpus,
model/effort or Reader/Expert requirement changes. Report coverage must disclose
limited-depth Expression assessment, including unresolved scope. Offline size
replay is a lossy record-budget comparison, not a new review or measured speedup.

## Shared guidance and object locators

New runs may pin `advisor_guidance: 1` with the source-bound
`inputs/expression_guidance.json`. Its analyst-authored operation catalogue is
prepared with the library, not regenerated for every manuscript. Each
case `operations` list supplies consolidated analyst guidance once per operation;
feature `operation_index` binds its conditions to the zero-based list item. The
index is omitted only for a single-operation case, where it is zero. Identical
cross-case guidance can share the ordinary exact-value transport encoding. Source IDs, feature IDs,
examples, conditions, prohibited uses, factual qualifications and limits remain
case-specific. Topic groups route related checks but do not establish equivalent
applicability. Every assigned case and use still needs an explicit judgment.

Do not quote a rewritten operation as mentor wording or as an exact original
analytical account. Use retained original examples or other visible source fields
for actionable evidence. Local administration retains original operation fields
and the complete mapping; stale mappings fail before submission. Older frozen
runs retain their original view and output contract.

`advisor_locators: 1` supplies stable page-image, figure/table-caption and equation
label candidate IDs in `manuscript_locators`. `$object_anchor` expands to the
corresponding page and image-location description. Inspect the actual page before
making visual claims. Labels can be references, repeated, missing or distorted by
column extraction; ambiguity remains explicit. These are not certified formula
transcriptions or bounding boxes. Unlisted objects remain reviewable using a page
image and a concrete description. `$anchor` continues to copy exact text passages.



## Review and drafting views

New runs pin `advisor_review_view:1`. Advisor diagnoses requirements and expression issues and proposes modification directions, not final replacement prose. It receives every operation, individual condition, exception, factual qualification and original example, including source identity. Reusable `frame` templates and example drafting permission/pair metadata remain in frozen sources; they cannot be cited as visible review evidence. This conservative separation deliberately retains all examples because some encode decisive lexical or punctuation distinctions. It does not promise substantial input or latency reduction.

After merge and verification, `writing_transfer.packet` reloads complete selected Expression records from the frozen library for the drafting task. It does not use the slim review transport as a drafting source. Original wording permissions, adapted-example roles, frames and conditions apply at that stage; analyst abstractions never become mentor quotations. No source is dropped, no missing decision is inferred, and no extra screening review is added.


## Shared analyses and explicit source results

New adaptive runs pin `advisor_shared_results:1`; legacy runs retain their frozen contract. The generated request supplies the current schema. Concern and Expression independently inspect the full manuscript. Findings arise during that inspection, not from a preliminary task map or a Concern-only issue list. Share a manuscript analysis only when its location, actual defect and required action agree; preserve different source conditions and exceptions.

Write each analysis once, with actual evidence, counterevidence and judgment. Give every primary Concern and every Expression exactly one explicit result. Only non-action results with genuinely identical reasons may group enumerated IDs. Each actionable Expression retains its own applicability/contribution, source excerpt and origin, feature IDs and boundaries. A single source result may contain several distinct actions, including both necessary repairs and optional improvements; these keep separate evidence and conditions. The expanded expression_result_manifest binds all of them to that one explicit source result. The program derives relation/check/finding IDs, reverse references and transport records from these explicit judgments; it generates no new judgment. An optional manuscript-driven suggestion remains possible without an Expression match.

Library associations remain candidate relationships. Explain only actual adoption and encountered conflicts/uncertainty. The complete association manifest remains local; unlisted associations are `not_assessed`, never checked, rejected or found inapplicable. Complete per-source accounting is distinct from exhaustive association-applicability auditing. Unknown and unfinished source/analysis counts remain visible in `source_review_summary` and the drafting evidence. Never describe those as resolved review.

The parser rejects missing/duplicate/unsupplied source IDs and invalid analysis links. Do not infer omitted decisions, silently deduplicate conflicting records or replace an absent card ID. Save original output and defects. If a later recovery is authorized, provide only affected sources plus necessary target evidence and dependencies, and preserve provenance; this protocol does not authorize automatic model retries.

Concern results use `writing_scope:shared_analysis` only in the expanded program representation: it denotes the new accounting format, not a judgment that the source is content-only or editorial. Complete Concern sources and source-to-final lineage remain available to drafting.


### Shared-result interface details

Only primary Concern IDs are mandatory. Extra explicit results for other supplied context cards are preserved in `context_card_dispositions`, with their judgments, reasons and links; they cannot replace missing primary results. Unknown IDs and duplicate IDs remain errors. `analysis_id_map` preserves the original model analysis IDs and their generated relation/check/finding/suggestion identities, including references in prose. Both context judgments and analysis maps pass into drafting evidence.

Non-action `target_anchors` may be omitted, producing an empty anchor list only, never a judgment or an invented citation. Null or malformed supplied anchors remain invalid. Shared-result `scope` may be any nonempty description or a legacy category; preserve it verbatim. `preserved_dependencies` may be nonempty text or a nonempty list of nonempty strings, preserved without flattening. Older protocols retain their existing restrictions.

Shared-result image references may name a supplied `IMG:Pn` through `page_locator`; resolve it only to its exact supplied page. If a numeric page is also present, it must agree. Preserve the original description, reject unknown/conflicting IDs, and never infer coordinates or image observations. Structural replay passing does not endorse the model's underlying scientific or grammatical judgment.
