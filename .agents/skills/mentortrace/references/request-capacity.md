# Complete-request capacity across stages

New ordinary adaptive v1.2 runs pin `request_capacity: 1`. The old 950,000 UTF-8
byte rejection is not applied. Old frozen protocols remain unchanged. Use the
actual selected model's detected `automatic_capacity.json` for all stages:
effective context, output including reasoning, every image, system allowance,
text headroom and the separate transport character bound. Never equate bytes,
characters and tokens or lower reserves to force a fit.

The runner detects capacity before review. Object planning, Reader, Expert, Editor
and evidence follow-ups use complete losslessly encoded modules and context.
Retain Reader/Expert planning and independent Advisor inputs. Local preparation
without detected capacity is not clearance to send. Transport checks the actual
serialized prompt and image hashes immediately before submission.

Advisor and combined source/delivery checks retain their automatic complete-task
packers. Oversized merge/Verify requests create `capacity_plans/STAGE/plan.json`:
partition complete adjudication targets, repeat the full manuscript/shared evidence,
keep explicit cross-target references together and keep competing editorial
alternatives together. Every assigned target requires an explicit disposition.
Do not discard apparent duplicates based on an unseen target. Assembly preserves
every returned field, namespaces output IDs, and runs per-part and whole-stage
validators. Cross-part duplicates may remain; code infers no semantic equivalence.

After freeze, `prepare_revision_proposals.py` checks the complete draft. If needed,
it prepares `capacity_plan/plan.json`. Explicitly linked targets and changes on the
same source page stay together. Every part retains the full manuscript and supplied
writing evidence, including complete Expression sources. Submit single or split
prepared drafts through:

```text
python scripts/run_prepared_draft.py --draft DRAFT --model MODEL --effort EFFORT --service-tier default --settings-authorization AUTH.json
```

Use existing authorized settings; no batching confirmation is needed. Assembly
checks target coverage, attribution and Expression realization, preserving original
responses and composite provenance. Partial drafts are not author-deliverable.
The combined report still needs both complete delivery audits, including cross-part
coherence, conditions and bilingual meaning. Never submit an oversized canonical
request directly when it names a capacity plan; the runner submits the bound parts.

Planning makes no model calls. Failed/uncertain attempts are not blindly retried;
inspect saved completion first and reuse valid results with original provenance.
Do not ask users to select profiles or approve individual batches. If the full
manuscript/shared evidence or one inseparable target group cannot fit alone, save
the actual obstacle and report incomplete work once; never truncate or fabricate
completion. That is a real capacity limit, not the removed byte threshold.
