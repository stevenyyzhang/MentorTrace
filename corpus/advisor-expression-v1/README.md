# MentorTrace Expression v1

This bundled library contains 1,581 admission-reviewed conditional Expression
records and 1,863 stored language or paragraph-operation features; eligibility depends on the supplied evidence. The full
493-card Concern catalog was supplied during admission review. Items adding no
independent expression feature and uncertain items are not included.

Normal v1.1.0 CLI reviews load this snapshot for independent Advisor review and
related drafting. Use --expression PATH to select another frozen snapshot or
--no-expression to create an explicit baseline without Expression.

No original pages, images, private identity mappings or literal editorial-comment
examples are distributed. Needed mentor-proposed manuscript wording, fragments,
author before/deletion excerpts and analyst accounts retain distinct labels.
Analytical operations cannot serve as quoted mentor manuscript prose. Conditional
examples do not certify general mentor preference, adopted revisions or improved
rewriting. Final suggestions are newly generated for the target manuscript.

Project-authored analytical fields follow LICENSE-CORPUS.md. Retained historical
source excerpts do not acquire that license merely by inclusion; see
THIRD_PARTY_NOTICES.md at the repository root. Public inclusion follows the
project owner's instruction recorded in manifest.json.
